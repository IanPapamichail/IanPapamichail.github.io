
# Nickolas Adrian Papamichail · Portfolio

Personal site of a quantum software engineer working on quantum circuit optimization, quantum simulation and high-performance C++/Python.

**Live:** https://ianpapamichail.github.io

## Features

- three.js hero with layered, scroll-driven gradient landscape
- Smooth scrolling and light/dark section transitions (GSAP ScrollTrigger, Lenis)
- Live graphene tight-binding demo in the browser
- Filterable projects and skill proficiency bars
- Quick Q&A and downloadable CVs

## Stack

HTML · CSS · JavaScript · three.js · GSAP · Lenis. No build step, no server, no API keys.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Edit

- Projects, skills, Q&A: `assets/js/content.js`
- Page text: `index.html`
- CVs: `cv/`

## Deploy

GitHub Pages → Settings → Pages → Deploy from a branch → `main` / `(root)`.
